# revit-dynamo-tools

Dynamo and Python tools to automate repetitive Revit workflows, built from real needs in architecture and BIM projects.

## Tools

| Tool | Description | Type |
|------|-------------|------|
| [Parking Numbering by Path](parking-numbering/) | Numbers parking spaces sequentially following a path line drawn by the user. | Dynamo |
| [Schedule Batch Export to CSV](schedule-export/) | Exports every schedule in the model to CSV in one run, with a configurable delimiter. | Dynamo + Python |

More tools coming soon.

## Requirements

Each tool lists its own requirements in its folder. In general: Revit with Dynamo 3.2 or later.

## How to use

1. Open the tool's folder and read its README.
2. Download the `.dyn` file.
3. Open it in Dynamo from Revit and follow the instructions.

Test on a copy of your model first.
